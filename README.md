# Sweet Crumbs Bakery - Product Manager

Sweet Crumbs Bakery Product Manager adalah aplikasi web sederhana untuk mengelola data produk bakery menggunakan PHP dan MySQL.

## Fitur

- Menampilkan daftar produk
- Menambahkan produk
- Mengedit produk
- Menghapus produk
- Pencarian produk
- Pilihan kategori menggunakan dropdown
- Validasi data
- Validasi nama produk unik
- Prepared Statement
- PDO
- CSRF Protection
- Responsive layout

## Produk

Kategori yang tersedia:

- Cake
- Pastry
- Donat
- Cookies
- Roti

## Teknologi

- PHP
- MySQL
- PDO
- HTML
- CSS
- Laragon
